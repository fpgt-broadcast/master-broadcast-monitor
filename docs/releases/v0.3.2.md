# Broadcast Monitor 0.3.2: no false "YouTube isn't receiving" alarm

- **Fixed: false red alarm while live.** "LIVE on YouTube but YouTube isn't receiving the feed" could appear during a healthy broadcast. The monitor looked for the broadcast's stream key among only the first 50 keys on the channel. Restream creates a new key for every event (vMix's YouTube login and Studio can too), so the one in use was often missed. It's now looked up directly, whatever the number of keys.
- **"Can't tell" is no longer "not receiving".** If a broadcast's stream key can't be read (for example, it belongs to another channel), the bar turns yellow with *"Can't check whether YouTube is receiving"*, and red is kept for problems the monitor can actually see.

## Download

- **Windows:** `BroadcastMonitor.exe`. Save it over the old one in the same folder. If Windows warns about an unknown publisher: **More info → Run anyway**.
- **Mac:** `BroadcastMonitor-0.3.2-macos.zip`. Unzip, replace the old app, right-click **Broadcast Monitor** → **Open** the first time.
- **Linux:** `BroadcastMonitor-0.3.2-linux-x64.tar.gz`

Your settings in `Documents/Broadcast Monitor` are kept.
