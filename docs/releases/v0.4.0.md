# Broadcast Monitor 0.4.0: security fixes

- **Fixed: other sites' pages could change settings.** Broadcast Monitor has no login, and a web page open in a browser on the network could change its settings with a plain form post. For example, it could change where alerts go, or the numbers your Twilio account texts. Only the dashboard's own pages can change settings now.
- **Open it by IP, `localhost`, the computer's name or a `.local` name.** Other names are refused, so a web page can't reach it through your browser. If you need a real DNS name, add it with `BM_ALLOWED_HOSTS`.
- A vMix or ScoreConnect address starting with `-` is refused.

## Download

- **Windows:** `BroadcastMonitor.exe`. Save it over the old one in the same folder. If Windows warns about an unknown publisher: **More info → Run anyway**.
- **Mac:** `BroadcastMonitor-0.4.0-macos.zip`. Unzip, replace the old app, right-click **Broadcast Monitor** → **Open** the first time.
- **Linux:** `BroadcastMonitor-0.4.0-linux-x64.tar.gz`

Your settings in `Documents/Broadcast Monitor` are kept.
